# Portfolio-ready project overview (edit to reflect your actual contributions)

**Project:** Verve — Event Discovery & Booking

**Type:** Responsive event discovery and demo reservation application

**Technologies:** HTML5, CSS3, JavaScript (ES6+), Font Awesome SVG, Unsplash photo URLs, Web Storage API; optional full-stack edition: Python, Django, Django ORM, SQLite, Django sessions, JSON API.

**What it does:** Visitors explore fictional events, filter by category, city and date, view an interactive event calendar, save favourites, inspect event details, select a ticket type and quantity, and create a demo booking with a confirmation reference. They can manage and cancel their browser-local demo reservations or download a calendar reminder. A simple organiser form lets visitors create fictional events; the optional Django edition stores bookings and hosted events on the server for each anonymous session.

**Key technical considerations:** Responsive components; event-driven DOM updates; input validation; escaped text before inserting user content into HTML; localStorage persistence for the static edition; graceful image fallbacks; accessible buttons and native dialogs; back-end session isolation and CSRF handling in the Django edition.

**Limitations:** Fictional events, no real authentication, payments, admission tickets or email delivery. Do not advertise this as a commercial production booking system.
